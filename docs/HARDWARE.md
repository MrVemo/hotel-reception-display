## ⚡ Stromverbrauch

- Pi 4B + 7" Touch Display: ~6W kontinuierlich
- Pro Jahr (24/7): ~52 kWh = ~15€/Jahr (bei 30ct/kWh)

## 🔧 Optional / Nice-to-have

- USB-Tastatur für Erstkonfiguration (Logitech K400 Plus ~40€)
- USB-C Verlängerungskabel (falls Steckdose weiter weg)
- MicroSD-Kartenleser für lokale Backups
- Mehrfachsteckdose mit Überspannungsschutz

## 🏠 Gehäuse (3D-Druck — Phase 2)

Für den **Standfuß** (45° Neigung) wird noch ein OpenSCAD-Modell erstellt, das auf einem 3D-Drucker gedruckt werden kann. Das offizielle Berrybase-Gehäuse ist flach, ein individueller Standfuß macht den Aufsteller komplett.
